Active Query Synthesis for Learning from Preferences

Generate pairwise comparisons that are both informative and easier to answer, without exhaustively scoring a large query pool.

Namrata Nadagouda · Nauman Ahad · Maegan Tucker · Mark A. Davenport

Read paper ↗

01 / Motivation

A useful query must be informative and answerable.

Standard pairwise comparison response models can treat every comparison as equally reliable. In practice, near identical options are difficult to distinguish, while highly dissimilar options may lack a meaningful common ground for comparison.

02 / Method

From response reliability to closed-form query geometry.

The framework localizes an unknown preference vector with Bayesian updates and chooses the next pair by maximizing mutual information.

Confidence aware response model

Reliability depends on the geometry of the pair.

The model uses heteroskedastic noise tied to distances between the user and each candidate, naturally discouraging comparisons that are too close or too far apart.

Approximation methods

Lower dimensional datasets

Pair M-dist

A Hessian induced Mahalanobis metric filters candidate pairs before mutual information refinement.

Higher dimensional datasets

Pair Opt-dist

An optimality based surrogate filters candidate pairs by midpoint, direction and distance deviations, avoiding the expensive Hessian.

Query Synthesis method: Info-Synth

Center at the posterior mean.

The optimal query midpoint lies at the current posterior mean, ensuring equi-probability of the response outcomes.

Align with maximum uncertainty.

The pair is oriented along the principal eigenvector of the posterior covariance; its distance follows from a one-dimensional optimization.

03 / Evaluation

One framework, four evaluation settings.

The evaluation spans a user study, synthetic preference learning, a fixed text summary dataset, and continuous controller tuning.
